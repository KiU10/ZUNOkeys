⌨️ ZUNOkeys

ZUNOkeys is a browser-based touch-typing learning platform inspired by TypingClub and EdClub.

The goal is to help users learn proper 10-finger typing, improve their typing speed and accuracy, and track their progress.

🚀 Project Goals

ZUNOkeys combines structured typing lessons with free practice.

Core Features

* Interactive Lessons: Learn touch typing step by step, starting with the home row.
* Free Practice: Practice with custom or predefined texts.
* Live Feedback: Instantly recognize correct and incorrect keystrokes.
* Typing Statistics: Track words per minute (WPM), accuracy, and errors.
* Progress Tracking: Save completed lessons and personal progress.
* Gamification: Earn XP, unlock levels, maintain streaks, and collect achievements.

🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript

No frameworks are required for the initial version.
